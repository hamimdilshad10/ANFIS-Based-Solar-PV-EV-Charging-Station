# Grid-Connected ANFIS-Based Energy Management in Solar PV EV Charging Station

## Overview

This project presents a MATLAB/Simulink model of a grid-connected solar PV-based EV charging station incorporating an Adaptive Neuro-Fuzzy Inference System (ANFIS) for energy management and MPPT control.

The system integrates solar photovoltaic generation, battery energy storage, EV charging, and grid interaction to improve renewable energy utilization and manage power flow under varying operating conditions.

## System Components

- Solar PV array
- Maximum Power Point Tracking (MPPT)
- ANFIS-based control
- Battery Energy Storage System (BESS)
- EV charging system
- Grid connection
- Power electronic converters
- Energy management system

## Control Strategy

The project uses ANFIS-based control to manage the power flow within the PV-EV charging system.

The control strategy considers the operating conditions of the system and coordinates PV generation, battery storage, EV charging demand, and grid power exchange.

The repository contains the ANFIS controller files and training dataset used in the simulation.

## How to Run

1. Download or clone this repository.
2. Open MATLAB.
3. Place all repository files in the MATLAB working directory.
4. Open `Solar_EV_Charging_Station_ANFIS_MPPT_project.slx`.
5. Ensure the required `.fis` and `.mat` files are available in the MATLAB path.
6. Run the Simulink model.
7. Observe the PV generation, battery operation, EV charging and grid interaction.

## Project Objectives

- Integrate solar PV generation with EV charging.
- Utilize battery energy storage for energy management.
- Implement ANFIS-based control.
- Extract maximum available power from the PV system using MPPT.
- Coordinate power exchange between PV, battery, EV and grid.
- Improve renewable energy utilization and system reliability.
